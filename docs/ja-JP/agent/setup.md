# Koharu Agent のセットアップ

Koharu Agent はプロジェクトを理解する内蔵クライアントです。ChatGPT サブスクリプションの Codex か、xAI アカウントの Grok を選べます。どちらもデバイスコード認証を使い、API キーは要求しません。サインインはプロバイダーごとに保持されます。

## サインイン

1. プロジェクトを開き、右側の**エージェント**パネルを選びます。
2. **Codex** または **Grok** を選び、サインインします。
3. ブラウザーで開いた認証ページに表示コードを入力します。
4. 承認して Koharu に戻り、アカウントとモデル一覧を待ちます。

同時に実行できるサインインは 1 つです。再試行前に既存の試行をキャンセルしてください。

## エージェント設定

選択中のプロバイダーのモデルと推論レベルを選びます。高い推論レベルは長く曖昧な編集に役立つ場合がありますが、時間もかかります。プロバイダーを切り替えると現在の会話は消去されますが、もう一方のサインインは残ります。設定は翻訳プロバイダーとは別に保存されます。

エージェントは開いているプロジェクトの意味状態を初期コンテキストにします。全ページ画像を自動アップロードしません。視覚確認ツールを呼んだページだけをレンダリングして添付します。

## アカウント境界

Agent 認証と **設定 -> プロバイダー**の認証情報は別です。Grok にサインインすると、その言語モデルがモデル選択に表示されます。翻訳モデルは自分で選ぶまで変わりません。API キーを保存しても Agent にはサインインしません。

**サインアウト**は実行中作業をキャンセルし、Agent セッションを消去して、選択中のプロバイダーの認証だけを解除します。
