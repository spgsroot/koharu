# 画像修復とインペイント

インペイントは原文文字を除去した部分の画像を再構築します。最大のモデルを使うことより、正確な除去範囲を作ることが重要です。

## 自動修復

検出は吹き出し内の文字と、絵の上の文字・効果音を分離した、互いに重ならないマスクを作ります。均一な吹き出し背景は推論なしで塗りつぶし、残りを LaMa/AOT で修復してから、別途選んだモデルで絵の上の文字を除去します。後者の既定は FLUX.2 Klein 9B です。変更はマスク内だけに保存されます。マスクが空ならモデルを読み込みません。古い結合マスクだけのページは、先にページ全体で検出を再実行してください。

通常サイズと拡大表示の両方で、文字片、消えた吹き出し線、繰り返し模様、にじんだトーン、文字外の変化、小さな句読点やルビの漏れを確認してください。

## 手動修復ブラシ

**削除**（`J`）は選択した吹き出し用 LaMa/AOT モデル、**検閲除去**（`D`）は独立した検閲除去モデルとプロンプトを使います。ブラシ直径を設定し、修復したい部分だけを塗ります。ストロークを離すと対応する処理が始まるため、別途実行ボタンを押す必要はありません。手動マスクはその処理だけ保存済みマスクに代わり、検閲除去では保存済み検閲マスクも不要です。

吹き出し全体を覆わず、制御しやすい複数ストロークを使います。文字を消せる範囲は含めつつ、線画や枠を避けてください。誤ったマスクはジェスチャーをキャンセルします。

## 手動ラスター修正

再推論より確実で速い場合は**描画**と**消しゴム**を使います。近くの色を取得し、必要最小限のブラシで作業し、最後に通常ズームで確認します。

## モデルを選ぶ

吹き出し用に LaMa または AOT を選びます。絵の上の文字用には独立したモデル、プロンプト、サンプリング設定があり、既定は FLUX.2 Klein 9B です。直接モデルを絵の修復にも使えますが、複雑な線画をにじませることがあります。検閲除去は別の生成モデル設定を持ち、文字修復にそのプロンプトを渡しません。[ビジョンとインペイントモデル](/ja-JP/models/vision-and-inpainting/)も参照してください。

自動の**インペイント**や**検閲除去**を再実行すると、選択範囲のマスク内だけを更新し、もう一方の段階が生成した画素を含め、それ以外の修復を保持します。削除・検閲除去ブラシ、または修復レイヤーへの描画・消しゴムでユーザーが編集したページは、どちらの自動段階も飛ばします。自動で作り直すには、そのページの修復レイヤーを削除してからインペイントと検閲除去を再実行してください。検出漏れや生成の乱れは引き続き目視確認してください。
