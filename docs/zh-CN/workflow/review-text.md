# 审校文本与图层

Koharu 把原稿分析、语义文本和视觉呈现分开。因此可以修正 OCR 而不移动文本框，也可以重新排字而不丢失原文区域来源。

## 检查文本图层

在画布或图层检查器中选择文本图层。一个文本项目可以包含原文及检测语言、译文及目标语言、排字与书写方向，以及手工几何或到检测区域的自动适配关系。

OCR 错误时编辑原文；措辞、语气、专名或断行需要人工判断时编辑译文。Koharu 只渲染译文，只有原文的图层不会在导出时突然显示。

## 图层操作

真实页面层级可包含组、文本、栅格、图像与画面图层。可以多选、移动层级、切换可见性、调整不透明度、删除图层及其子项，并编辑文本内容、几何和排字。

分析区域不是呈现图层。它们描述模型在原稿中找到的内容，不会与可见文字或画面争夺选择。

## 撤销与重做

使用**编辑 -> 撤销**（`Ctrl+Z`）和**重做**（`Ctrl+Shift+Z`；Windows/Linux 也可使用 `Ctrl+Y`）。**历史记录**标签会列出命名编辑和每个流水线阶段；选择一行即可跳转到该状态。在旧状态上继续编辑会丢弃其后的历史。

使用相机按钮保存命名快照，之后可恢复或删除。清除历史会保留当前状态和命名快照。历史与快照仅属于当前会话；关闭并重新打开项目后不会恢复。

建议逐页检查：检测区域、OCR 原文、译文含义、清除痕迹、适配与排字，以及正常阅读尺寸下的最终合成。
