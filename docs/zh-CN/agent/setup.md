# 设置 Koharu 智能体

Koharu 智能体是内置的项目感知客户端。可以选择使用 ChatGPT 订阅的 Codex，或使用 xAI 账户的 Grok。两者都使用设备代码认证，不会要求 API Key。每个提供方各自保留登录状态。

## 登录

1. 打开项目并选择右侧的**智能体**面板。
2. 选择 **Codex** 或 **Grok**，然后登录。
3. Koharu 会在浏览器中打开设备授权页面。
4. 输入显示的设备代码并批准登录。
5. 返回 Koharu，等待账号与模型列表载入。

同一时间只能进行一次登录。重试前请取消现有尝试。

## 配置智能体

为当前提供方选择模型与推理级别。较高推理级别可能更适合长而模糊的项目修改，但耗时更长。切换提供方会清除当前对话，但不会删除另一个提供方的登录。智能体配置与翻译服务设置分开保存。

智能体使用当前项目的语义状态作为初始上下文，不会自动上传所有页面。只有它调用视觉页面检查工具时，指定页面才会被渲染并附加。

## 账号边界

智能体认证与**设置 -> 服务商**中的凭据相互独立。登录 Grok 后，其语言模型会出现在模型选择中；在你主动选择之前，当前翻译模型不会改变。保存 API Key 也不会登录智能体。

**退出登录**会取消活动任务、清除当前智能体会话，并只移除当前提供方的授权。
